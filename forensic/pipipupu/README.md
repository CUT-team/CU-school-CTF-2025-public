# Pipipupu | Easy | Forensic

## Информация

> Подслушал где-то какие-то пи-пи и пу-пу, не понимаю, о чем это, но, может, поймете вы? 
> 
> Ответ нужно обернуть в формат флага самостоятельно. Например, если ответом будет слово CUETA, то флаг - cuctf{CUETA} 

## Выдать участникам

public/pipipupu.wav

## Описание

тональные DTMF звуки набора телефона

## Решение

Открыть спектрограмму, смотреть на частоты и выписать ключи по табличке, найденной в интернете

## Флаг

`cuctf{880055536361905}`
