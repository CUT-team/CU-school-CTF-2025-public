## Описание

Дан флаг, зашифрованный с помощью snow_1.0. Нужно восстановить флаг.

## Решение

Так как каждый итоговый байт шифра b = a ^ c, где а - исходный байт и c - байт keystream, то зная начало флага (cuct), мы можем восстановить первые два keystream. 

Уязвимость алгоритма заключается в том, что LFSR и FSM не были инициализированы отдельно. Как результат, ко второму циклу алгоритма мы можем вычислить значения LFSR и FSM, зная только LFSR[0] (key[0]). Зная LFSR и FSM мы вычисляем сам keytstream[1] и сверяем с его настоящим значением, которое мы уже получили xor'ом с байтами 'ct', Значит перебором только key[0] возможно узнать значение всех переменных на втором цикле.

  ```cpp
  LFSR[0] = key_0_init;
  for (int i = 0; i < 15; ++i){
      LFSR[i + 1] = (LFSR[i] >> (1)) + ((((LFSR[i] >> 15)) ^ (LFSR[i] & 0x1)) << 16);
  }
  uint16_t FSM_R1_0 = 0xFFFF - LFSR[15];
  uint16_t FSM_R1_1 = LFSR[15];
  uint16_t FSM_R2_1 = (SBOX[(0xFF00 & FSM_R1_0) >> 8] << 8) + SBOX[0x00FF & FSM_R1_0];
  ```
     
Как только состояние LFSR и FSM во втором цикле определено, мы можем восстановить весь поток ключей и расшифровать флаг, следуя обычному процессу дешифровки.
