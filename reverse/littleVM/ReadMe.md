
# LittleVM | easy | reverse

## Задание
- Бинарь: `vmception` (ELF x64)  
- Байткод: `task.vmcode`


## Логика VM
- 8 регистров, память 256 байт, простой интерпретатор.
- Инструкции:
  - `0x01 reg, imm` — `LOAD_REG`
  - `0x03 r1, r2` — `XOR`
  - `0x04 r1, r2` — `CMP`
  - `0x05 addr` — `JNE`
  - `0x06 reg` — `PRINT`
  - `0xFF` — `HALT`
- `LOAD R1,0x00` обрабатывает ввод `getchar()`.

## Маскировка флага
- **Ключ**: ASCII строка `"V1rTuAL"` (7 байт).
- Для каждого символа флага:
  1. `R1 = getchar()`  
  2. `R7 = key[i mod 7]`  
  3. `R1 ^= R7`  
  4. Сравнение с заранее записанным байтом `(flag[i] ^ key[i mod 7])`
  5. При несовпадении — `HALT`.
- **Вывод**: для каждого байта:
  1. `LOAD R0, encoded`  
  2. `R7 = key[i mod 7]`  
  3. `R0 ^= R7`  
  4. `PRINT R0`

## Решение
1. Изучить VM и набор инструкций.
2. Обнаружить, что флаг **не хранится явно** — вместо этого хранятся байты `flag[i] ^ key[i]`.
3. Распознать ключ `"V1rTuAL"`.
4. Дешифровать: `decoded[i] = encoded[i] ^ key[i mod 7]`.
5. Получить флаг:  
   ```
   V1rTuAL_MaCH1nEs
   ```
