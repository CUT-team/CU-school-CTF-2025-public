# uCUCUCUCUga | Hard | Misc
## TL;DR
Код на самом деле является написанным на языке `Brainfuck`. Лишь запуска недостуточно -
чтобы получить полный флаг, потребуется этот код пореверсить и попринтить ячейки памяти.

## Решение
Код на `Go` не имеет никакого смысла. На самом деле внутри скрыт код на языке `Brainfuck`.
В BF любые символы кроме инструкций (`>`, `<`, `+`, `-`, `.`, `,`, `[`, `]`)
считаются за комментарии и игнорируются интерпретатором. Однако даже если догадаться,
что код на самом деле на BF, лишь его запуска будет недостаточно, потребуется
также его пореверсить. Для удобства отфильтруем инструкции языка BF, тогда код будет
будет выглядить так:
```brainfuck
>.<++++++++[>.++++++++++,,,+++[>+>+>+>+>+>+>++>++<<<<<<<,<-
]>,->+,>,->,+>-,>,+,>,->,+,<<<<<<<<.<-<-+>]>>,+++.>+++++.>+
++.>++++.,>++++++.>+++++++++++.>>>++++++++++++++++++++[<-+-
----+,-<,,,+--------++<-,---<+<---<<---<+>,>>>>>>>-]<+<----
-<++++++++<+------+<--------,<+++++++++<------<>>>>>>.<<<<>
>>>>,.<-+<--<---------------<+++++++++++++++++++<----------
------------->.<.>.<.>>.------.>>.<<<<<<--------->>>>>><<<<
>>>>>++++++++.
```
Он выведет всего часть флага.

Если смотреть память и на байтовых операциях попроставлять `.`, то рано или поздно
получится найти все байты для флага (они появляются в памяти последовательно).
Важно также сказать, что если для кода BF сделать минификацию, то лишние подсказочные
переходы по ячейкам будут утеряны. И за памятью тогда пришлось бы следить после каждой
инструкции добавления/уменьшения. Правильные места для чтения представлены в
следующем коде (они обведены в скобки):
```brainfuck
>.<++++++++[>.++++++++++,,,+++[>+>+>+>+>+>+>++>++<<<<<<<,<-
]>,->+,>,->,+>-,>,+,>,->,+,<<<<<<<<.<-<-+>]>>,+++.>+++++.>+
++.>++++.,>++++++.>+++++++++++.>>>++++++++++++++++++++[<-+-
----+,-<,,,+--------++<-,---<+<---<<---<+>,>>>>>>>-]<+<----
-<++++++++<+------+<--------,<+++++++++<------<(.)>(.)>>>>>
.<<<<(.)>(.)>(.)>(.)>(.)>,.<-+<--<---------------<+++++++++
++++++++++<----------------------->.<.>.<.>>.------.>>.<(.)
<<<<<---------(.)>>>>>>(.)<<<(.)<(.)>>>>>++++++++.
```
Таким образом получится достать полный флаг.
