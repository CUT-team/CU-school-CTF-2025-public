# uCUCUCUCUga | Hard | Misc
## TL;DR
Код на самом деле является написанным на brainfuck. Для того, чтобы получить полный флаг, потребуется этот код пореверсить и попринтить байты

## Решение
Код на Go не имеет никакого смысла. На самом деле внутри скрыт код на языке brainfuck. В brainfuck любые символы кроме инструкций (`>`, `<`, `+`, `-`, `.`, `,`, `[`, `]`) считаются за комментарий и игнорируются интерпретатором. Однако даже если догадаться, что код представляет собой brainfuck, просто его запуска будет недостаточно, потребуется также его отреверсить. После фильтрации инструкций код на bf будет выглядить так:

```brainfuck
>.<++++++++[>.++++++++++,,,+++[>+>+>+>+>+>+>++>++<<<<<<<,<-]>,->+,>,->,+>-,>,+,>,->,+,<<<<<<<<.<-<-+>]>>,+++.>+++++.>+++.>++++.,>++++++.>+++++++++++.>>>++++++++++++++++++++[<-+-----+,-<,,,+--------++<-,---<+<---<<---<+>,>>>>>>>-]<+<-----<++++++++<+------+<--------,<+++++++++<------<>>>>>>.<<<<>>>>>,.<-+<--<---------------<+++++++++++++++++++<----------------------->.<.>.<.>>.------.>>.<<<<<<--------->>>>>><<<<>>>>>++++++++.
```

Если отдебажить память, либо на байтовых операциях попроставлять `.`, рано или поздно получится найти все байты для флага (они появляются в памяти последовательно). Правильные места для чтения представлены в следующем коде (они обведены в скобки):
```brainfuck
>.<++++++++[>.++++++++++,,,+++[>+>+>+>+>+>+>++>++<<<<<<<,<-]>,->+,>,->,+>-,>,+,>,->,+,<<<<<<<<.<-<-+>]>>,+++.>+++++.>+++.>++++.,>++++++.>+++++++++++.>>>++++++++++++++++++++[<-+-----+,-<,,,+--------++<-,---<+<---<<---<+>,>>>>>>>-]<+<-----<++++++++<+------+<--------,<+++++++++<------<(.)>(.)>>>>>.<<<<(.)>(.)>(.)>(.)>(.)>,.<-+<--<---------------<+++++++++++++++++++<----------------------->.<.>.<.>>.------.>>.<(.)<<<<<---------(.)>>>>>>(.)<<<(.)<(.)>>>>>++++++++.
```

Таким образом в интерпретаторе bf увидим флаг
