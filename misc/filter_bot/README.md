## Развертка

Добавить бота в беседу с участниками, всем огранизаторам дать в чате тг админки с подписью "организатор", боту дать просто админку в тг

## Описание
Телеграм спамфильтр-бот с кривой проверкой на адмику

## Решение

Бот выглядит как обычный антиспам, но если написать /help, то мы видим список доступных команд. Из этих команд нас интересует /report - к ней у участников нет доступа и пишет "вы не являетесь организатором". Надо создать свою группу в тг и добавить туда этого бота и выдать себе админку с названием "организтор", тогда можно глянуть /report 0 - флаг

## Флаг

`cuctf{H4LL0_ORgAn1SAT0rS}`
